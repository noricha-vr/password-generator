# ランダムパスワード生成ツール

いろんなタイプのパスワードを自動生成し、ワンクリックでコピーやダウンロードができるウェブアプリケーションです。

## 🔐 セキュリティと安全性

### クライアントサイドで完結
このアプリケーションは**完全にブラウザ上で動作**し、生成されたパスワードは**サーバーに送信されません**。

- ✅ すべての処理はあなたのブラウザ内で実行されます
- ✅ ネットワーク通信は一切発生しません
- ✅ パスワードはどこにも保存・送信されません
- ✅ 外部APIやサービスに依存していません

### 暗号学的に安全な乱数生成

パスワード生成には、ブラウザ標準の **Web Crypto API** を使用しています。

```typescript
crypto.getRandomValues(array)
```

**特徴:**
- **暗号学的擬似乱数生成器（CSPRNG）** を使用
- OSのエントロピープールから乱数を取得
- 予測不可能で統計的に均一な乱数
- `Math.random()` のような脆弱な方法は使用していません

**参考:**
- [MDN: Crypto.getRandomValues()](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues)
- [W3C Web Cryptography API](https://www.w3.org/TR/WebCryptoAPI/)

### オープンソース

## 🚀 機能

### 11種類のパスワードタイプ

1. **英数字 (16文字)** - 標準的なパスワード
2. **英数字 (24文字)** - より長いパスワード
3. **英数字+記号 (16文字)** - 強力なパスワード
4. **英数字+記号 (24文字)** - より長い強力なパスワード
5. **数字のみ (8桁)** - 数字コード
6. **PINコード (6桁)** - ATMやスマホ用
7. **UUID** - ユニバーサルユニーク識別子
8. **HEX (32文字)** - 16進数文字列
9. **HEX (64文字)** - より長い16進数
10. **Base64** - Base64エンコード文字列
11. **覚えやすいパスワード** - 単語と数字の組み合わせ（例: `Dragon-Ocean-Mountain-742`）

### 便利な機能

- ✅ ページアクセス時に自動生成
- ✅ ワンクリックでクリップボードにコピー
- ✅ 個別のパスワードをテキストファイルとしてダウンロード
- ✅ 全パスワードを一括ダウンロード
- ✅ 個別・一括の再生成機能
- ✅ レスポンシブデザイン（スマホ、タブレット、PC対応）
- ✅ ダークモード対応

## 🛠️ 開発

### 必要な環境

- Node.js 20以上
- Bun 1.0以上（推奨）

### セットアップ

```bash
# 依存関係のインストール
bun install

# 開発サーバーの起動
bun run dev

# ビルド
bun run build

# プレビュー
bun run preview
```

### プロジェクト構造

```
src/

│   ├── passwordGenerator.ts    # パスワード生成ロジック
│   └── downloadUtils.ts         # ダウンロード機能

├── App.tsx                      # メインアプリ
├── index.css                    # Tailwind CSS設定
└── main.tsx                     # エントリーポイント
```
